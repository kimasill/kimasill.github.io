게임과 서버 개발에서 쌓은 경험을 바탕으로, 현재는 풀스택과 AI 기반 서비스 개발로 전문 영역을 넓히고 있습니다. 사용자 경험을 이해하고, 이를 뒷받침하는 데이터 처리와 시스템 구조를 함께 설계하는 데 강점이 있습니다. 한국수자원공사 협업 프로젝트인 CLEARIX 개발에 참여해, 수처리 시계열 데이터를 기반으로 합성 데이터를 생성하고 품질을 검증하는 엔진을 구현했습니다. Python·FastAPI를 활용해 입력 데이터 검사부터 생성·검증·결과 출력까지 이어지는 파이프라인을 담당했습니다. 작업 상태 관리와 취소·중단 후 복구 기능을 구현하고, 입력 파일의 무결성을 확인하며 검증을 통과한 결과만 저장하도록 설계했습니다. 또한 UI 개발팀과의 협업을 위해 API 명세와 데이터 규격을 문서화했습니다. 이전에는 절차적 콘텐츠 생성(PCG) 기반 레벨 생성 모듈과 데디케이티드 서버 기반 2D MMORPG의 네트워크 환경을 구축했으며, 딥러닝 분류 모델을 개발했습니다. 상용 엔진뿐 아니라 Java와 C# 라이브러리만으로도 게임을 구현하며, 필요한 기능과 구조를 직접 설계하고 완성하는 역량을 쌓았습니다. 복잡한 요구사항을 구현 가능한 기능으로 구체화하고, 데이터 흐름과 예외 상황까지 고려해 시스템을 설계합니다. 새로운 기술을 실제 문제 해결에 적용하며, 동료가 이해하고 확장할 수 있는 구조와 문서를 함께 만드는 것을 중요하게 생각합니다.
